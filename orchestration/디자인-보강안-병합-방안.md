## 4. 자산·기술 확인

- **브랜드 SVG 3종**: 사이트에 이미 동일 패스 존재 (`brand-mark.tsx`, `public/brand/`) — 이식 불필요 ✅
- **support.js**: dc 미리보기 런타임 — 구현과 무관, 참고용 보관
- 디자인의 reveal 스크립트는 기존 `reveal.tsx`와 동일 원칙(JS가 숨기고 JS가 되살림) — 기존 컴포넌트 재사용, 새 로직 불필요
- 애니메이션은 전부 순수 CSS keyframes — 패키지 추가 불필요, globals.css에 keyframes 추가로 대응

## 5. 실행 방안 (권장)

**S7 세션 신설** (지시서: `sessions/S7.md`) — 실행 시점: **S4 병합 후** (page.tsx 히어로를 양쪽 다 만지므로 순차 필수), S6 최종 검증 전.

```
S4 병합 → S7(디자인 모션 이식) → S6(최종 검증) → 초안 확정
```

- S7도 동일 규정: 전용 워크트리(wt/s7), 용어 규칙 절대 준수(새 문구도), 커밋 `S7:`, 핸드오프 필수
- 위험도: 낮음 — 시각 레이어만 추가, 문구·구조·데이터 불변. 실패 시 해당 커밋만 드롭하면 초안에 지장 없음
