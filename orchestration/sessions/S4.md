## 작업 범위

### A. 플로팅 통합 문의 위젯 (명세 9-8) — 신규 컴포넌트
- 위치: 화면 오른쪽 아래 고정 런처. 접혀 있다가 클릭 시 채널 목록 펼침.
- 채널 5개: ① 전화 ② 문의 폼(`/quote`) ③ SMS ④ 카카오톡 채널 ⑤ 챗봇
- 카카오톡·챗봇은 미개설 — 버튼은 노출하되 클릭 시 "준비 중입니다" 안내(토스트/작은 팝업) 후 `/quote` 유도
- 모바일 하단 CTA바(`mobile-cta-bar.tsx`)와 겹치지 않게 위치 조정

### B. 기기별 버튼 분기 (명세 9-3~9-5, 동작 매트릭스)
- 공용 유틸/컴포넌트로 구현 (예: `ContactAction` 컴포넌트 또는 훅):
  - 전화류: PC → `/quote` 이동 / 모바일 → `tel:` (site.telHref)
  - 문의(SMS)류: PC → `/quote` / 모바일 → `sms:01098283637?body=<문구>` (문구는 sample.ts 에 더미로: "지성크리닝 문의드립니다. 업체명: / 품목: / 물량: ")
- 적용: 헤더 전화 영역, 히어로·CTA 전화 버튼, 모바일 CTA바, 견적 연락 카드, 푸터 전화, 플로팅
- 판별은 CSS 미디어쿼리 우선(`lg:` 분기로 두 요소 렌더), JS UA 스니핑 지양

### C. 후기 마퀴 섹션 (명세 4-3, 9-1)
- 견적 문의(`/quote`) 폼 아래 배치. 카드가 **왼쪽으로 연속해 흐르는 마퀴** (CSS keyframes, 카드 목록 2회 렌더로 무한 루프, `prefers-reduced-motion` 시 정지)
- 더미 후기 3~5개를 `lib/sample.ts` 에 추가: "김○○님 · 펜션" + 한 줄 (예: "친절한 상담이었어요", "세탁물이 깨끗하게 와요") — 실명·실업체 금지

### D. 자동 슬라이드 배너 (명세 8-6)
- 홈 히어로 하단 또는 회사소개에 자동 넘김 슬라이드 컴포넌트 (5~7초 간격, 수동 넘김 화살표/점 포함)
- 슬라이드 데이터는 `sample.ts` 에: 현재 확보된 지성이엔지 콘텐츠 2장 자리 + 더미 2장(플레이스홀더 일러스트 금지 — 단색 배경+텍스트 카드) = 4장 구성. 이미지 파일이 없으므로 텍스트 기반 슬라이드로 구현하고 이미지 교체 가능 구조로.
- 배치 위치가 애매하면 홈 히어로 아래로 하고 핸드오프에 질문 기록.

### E. SNS 버튼 (명세 9-6)
- 푸터 + 후기 섹션 부근에 인스타그램·네이버 블로그 아이콘 버튼. 링크는 개설 전 — 클릭 시 "준비 중" 안내. `sample.ts` 에 링크 자리.

### F. 더미 추적
- 이번 세션에서 추가한 모든 더미(sms 문구, 후기, 슬라이드, SNS 링크)를 `lib/sample.ts` 상단 주석의 더미 목록에 추가.
