## 작업 범위 — 명세 4-2 표를 5개 레이어에 일관 적용

| 레이어 | 파일 |
|---|---|
| UI | `src/components/quote-form.tsx` |
| 검증 | `src/lib/schema.ts` |
| 액션 | `src/app/quote/actions.ts` |
| 저장 | `src/lib/inquiries.ts` |
| 표시·메일 | `src/app/admin/inquiries/page.tsx`, `src/lib/mail.ts` |

필드 최종안:
- 유지(필수): 업체명, 성함(기존 "담당자" 라벨 변경), 연락처, 개인정보 동의
- 유지: 주소(기존 "사업장 지역" 라벨 변경, hint의 납품→배송), 이메일(선택), 문의 내용
- 삭제: 업종(industry), 세탁 품목(items), 예상 물량(volume), 희망 수거 주기(cycle)
- 필수 표시는 빨간 `*` 유지
- 동의 문구 내 수집 항목 나열을 새 필드 구성에 맞게 갱신 ("사업장 지역" → "주소" 등)

⚠️ **DB 주의**: `inquiries.ts` CREATE TABLE 의 industry 등은 NOT NULL — 기존 데이터 보존을 위해 **컬럼은 남기고 INSERT 시 빈 문자열 기본값**으로 처리한다(스키마 마이그레이션 금지). 코드의 입력·타입·표시에서만 제거.

접수 완료 화면: "담당자가 확인 후 연락드리겠습니다" 유지. "급하시면 전화가 가장 빠릅니다"는 유지하되 전화번호는 site.ts에서 (S1이 이미 교체).
