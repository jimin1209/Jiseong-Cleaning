## 작업 범위 — 병합 방안 D1~D11 전부

핵심 원칙: **현재 사이트의 문구·구조·데이터를 1글자도 바꾸지 않는다.** 시각·모션 레이어만 얹는다. 디자인 원본의 구 문구(린넨·고온·납품 등)를 절대 복사해 오지 말 것 — 스타일 값(색·크기·타이밍·keyframes)만 가져온다.

- D1 진행 바: `site-header.tsx`에 스크롤 진행 바 (기존 scrolled 상태 로직 확장)
- D2~D4, D8: `page.tsx` 히어로에 심볼 회전·글로우 이동·거품·웨이브 (keyframes는 `globals.css`에 jc* 이름으로 추가)
- D5 로테이팅 키워드: 기본형 "사업장 세탁물을" → "호텔 시트를" → "펜션 이불을" → "사우나 수건을" 순환. 접근성: aria-hidden 처리로 스크린리더에는 기본형만.
- D6 글래스 일정 카드: 신규 컴포넌트 `components/schedule-card.tsx` (교체 문구는 병합 방안 표 그대로). "예시 화면" 각주 유지.
- D7 마퀴 배지: S4가 만든 마퀴 컴포넌트가 재사용 가능하면 재사용, 아니면 같은 패턴으로. 문구는 병합 방안 D7의 교체 목록만.
- D9 서비스 카드 스타일: 통합 카드에 그라디언트 탑바+hover 리프트
- D10 절차 grow·순차 하이라이트: 새 4단계 문구는 그대로 유지
- D11: 모든 애니메이션 `prefers-reduced-motion: reduce` 시 비활성 (기존 reveal.tsx 원칙 준수)
