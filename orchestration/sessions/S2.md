## 작업 범위

### A. 서비스 통합 (명세 3절)
- `lib/services.ts`: services 3건 → 1건 통합(숙박 중심+월세탁 흡수, 주방 삭제). itemGroups 필드 제거. forWhom은 업종 목록(호텔·모텔·펜션·사우나·헬스장·단체시설)과 일치. reasons export 제거. priceNote는 유지하되 판매 강조 없는 톤인지 확인.
- `app/services/[slug]/` 삭제 → `/services` 단일 페이지로 재구성 (통합 서비스 소개: "안전한 세탁·살균을 거쳐 약속된 날짜에 수거, 배송해 드립니다" 중심, 명세 1-2 참조)
- 기존 `/services/linen` 등 → `/services` redirect (next.config가 아닌 Next 라우트 수준에서 가능한 방법 사용, 어려우면 핸드오프에 질문으로)

### B. 삭제 (명세 1절·8절)
- `app/facility/` 페이지 삭제
- 홈 `app/page.tsx`: 강점 섹션(1-4), 시설·공정 섹션(1-6), FAQ 섹션(1-8) 통삭제. 서비스 카드 영역을 통합 1카드(또는 카드 없이 소개형)로. "취급 품목 보기" 링크 제거. 장애인 표준사업장 섹션은 **유지**하되 인증번호 표기 제거(1-7).
- `lib/faq.ts`, `components/faq-list.tsx` 삭제 (홈·견적 페이지의 import 정리)
- `components/illustration.tsx` 및 사용처 제거 (그림 전부 제거)
- `components/price-table.tsx`, `lib/pricing.ts` 삭제 ([slug] 삭제로 사용처 소멸 확인 후)
- `components/sample-banner.tsx` 비표시 처리(8-2) — layout에서 렌더 제거. sample.ts의 SAMPLE_CONTENT 스위치는 유지(더미 관리용).
- 견적 `app/quote/page.tsx`: FAQ 섹션 제거, 운영시간 임시값 노출부는 "통화가 어려운 시간에는 폼으로" 문구 쪽으로 단순화

### C. 내비·사이트맵·푸터 (명세 5절)
- `app/sitemap.ts`: facility·services/[slug] 항목 제거
- `components/site-footer.tsx`: "안내"에서 시설·공정 제거, 서비스 링크 3개 → 단일 `/services`, "…가 운영하는 세탁 서비스" 문장을 "우수조달업체 (주)지성이엔지에서 운영하는…" 톤으로 통일
- nav 는 S1이 site.ts에서 이미 처리 — 확인만
