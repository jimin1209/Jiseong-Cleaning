# 01. 요구사항 · 기능 정의

## 1. 서비스 시나리오 (Happy Path)

```
① 고객이 앱에서 수거 신청 (날짜/시간대/품목 예상 선택)
        ↓
② 관리자(또는 자동 배차)가 기사에게 수거 배차
        ↓
③ 기사가 고객 집 방문 → 세탁물 수거 → 사진 촬영 → 수거완료 처리
        ↓
④ 기사가 세탁공장에 입고
        ↓
⑤ 공장이 QR 스캔 입고 → 품목 검수 → 실제 수량/품목 확정 → 최종 금액 산정
        ↓
   (예상보다 금액 증가 시) 고객에게 알림 → 고객 승인 → 진행
        ↓
⑥ 세탁 → 건조/다림 → 포장 → 출고대기
        ↓
⑦ 기사가 공장에서 출고 → 고객에게 배송 → 사진/서명 → 배송완료
        ↓
⑧ 결제 확정 (구독 회원은 횟수 차감, 초과분만 청구) → 리뷰 요청
```

---

## 2. 역할 정의

| 역할 | 코드 | 설명 | 계정 생성 방식 |
|---|---|---|---|
| 고객 | `CUSTOMER` | 세탁 서비스 이용자 | 셀프 가입 (휴대폰 인증) |
| 기사 | `DRIVER` | 수거·배송 담당 | 관리자가 생성/승인 |
| 세탁공장 | `FACTORY` | 검수·세탁 작업 처리 | 관리자가 생성 |
| 관리자 | `ADMIN` | 전체 운영·관제 | 최초 1개는 시드, 이후 관리자가 생성 |

> `ADMIN`은 `SUPER_ADMIN` / `STAFF` 2단계로 세분화 (정산·회원삭제 등 민감 기능은 SUPER만)

## 3. 고객 (CUSTOMER) 기능

### 3.1 계정 · 인증
| 기능 | 우선순위 | 비고 |
|---|---|---|
| 휴대폰 번호 인증 가입/로그인 | **MVP** | SMS 인증번호 6자리, 5분 만료 |
| 카카오 소셜 로그인 | 2차 | 가입 전환율 개선용 |
| 프로필 관리 (이름/연락처) | **MVP** | |
| 회원 탈퇴 | **MVP** | 개인정보 파기 정책 필수 |

### 3.2 주소
| 기능 | 우선순위 | 비고 |
|---|---|---|
| 도로명 주소 검색 (다음 우편번호 API) | **MVP** | |
| 주소 여러 개 저장, 기본 주소 지정 | **MVP** | 집/회사 라벨 |
| 상세 출입 정보 (공동현관 비번, 엘리베이터 등) | **MVP** | 문앞 수거에 필수 |
| 서비스 가능 지역 검증 | **MVP** | 지역 밖이면 신청 차단 + 안내 |

### 3.3 주문 (수거 신청)
| 기능 | 우선순위 | 비고 |
|---|---|---|
| 수거 날짜 + 시간대(슬롯) 선택 | **MVP** | 예: 09-12 / 12-15 / 15-18 / 18-21 |
| 세탁 유형 선택 (일반/드라이/이불/운동화/프리미엄) | **MVP** | 예상 수량 입력 (확정은 공장 검수 후) |
| 요청사항 메모 | **MVP** | |
| 비대면(문앞) 수거/배송 여부 | **MVP** | |
| 예상 금액 즉시 표시 | **MVP** | 최종 금액은 검수 후 확정임을 명시 |
| 배송 희망일 선택 | 2차 | 기본은 "세탁 완료 시 즉시" |
| 긴급(익일) 서비스 옵션 | 2차 | 할증 |

### 3.4 주문 추적
| 기능 | 우선순위 | 비고 |
|---|---|---|
| 실시간 상태 타임라인 | **MVP** | WebSocket 또는 폴링 |
| 기사 정보/연락처 (수거·배송 시) | **MVP** | 안심번호는 2차 |
| 수거/배송 사진 확인 | **MVP** | 비대면 시 증빙 |
| 검수 결과 확인 + 추가 금액 승인/거절 | **MVP** | 승인 없으면 세탁 미진행 |
| 기사 실시간 위치 지도 | 3차 | 운영 부담 대비 효용 낮음 |

| 건별 결제 (검수 확정 후 청구) | **MVP** | |
| 정기구독 가입/변경/해지 | **MVP** | 월정액, 월 N회 포함 |
| 구독 잔여 횟수 확인 | **MVP** | |
| 결제 내역 / 영수증 | **MVP** | |
| 쿠폰 / 적립 포인트 | 2차 | |

### 3.6 사후
| 기능 | 우선순위 | 비고 |
|---|---|---|
| 리뷰 작성 (별점 + 사진) | 2차 | |

## 7. 공통 · 비기능 요구사항

| 항목 | 내용 |
|---|---|
| 알림 | 웹푸시(FCM) + **카카오 알림톡**(필수, iOS 푸시 제약 대비) + SMS 폴백 |
| 개인정보 | 필드별 차등 암호화(문서 11 §4), 처리방침 고지·동의, 탈퇴 시 파기 + 거래기록 5년 보존(문서 11 §7) |
| 사진 보관 | 90일 후 자동 삭제 (분쟁 대비 기간) |
| 감사 로그 | 주문 상태·금액 변경 전량 기록 |
| 다국어 | 한국어만 (i18n 구조만 잡아둠) |
| 접근성 | 기사·공장 화면은 장갑 낀 손 기준 → 터치 타겟 최소 48px |
| 브라우저 | Chrome/Safari 최신 2개 버전, iOS 16.4+ (웹푸시 최소 요건) |

## 8. MVP 범위 확정

**1차 릴리스에 포함:**
고객 주문/추적/결제/구독 · 기사 수거배송 · 공장 검수세탁 · 관리자 관제/배차/마스터데이터

**1차에서 제외:**
소셜 로그인, 실시간 기사 위치, 쿠폰/포인트, 리뷰, 자동배차, 정산 자동화, 통계 리포트, 오프라인 모드
