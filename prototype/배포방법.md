# 목업 배포 — Netlify

원격에 계신 분과 공유하려면 URL이 필요하다. 아래는 30초짜리 작업이다.

## 1. 올리기

1. https://app.netlify.com/drop 접속
2. **`deploy` 폴더째로** 브라우저 창에 드래그해서 놓는다 (안의 파일이 아니라 폴더를 통째로)
3. 업로드가 끝나면 `https://무작위이름-abc123.netlify.app` 주소가 나온다

> ⚠️ 로그인하지 않으면 사이트가 일정 시간 뒤 사라진다.
> **GitHub 계정으로 로그인**해서 사이트를 계정에 붙여두면 계속 유지된다.

## 2. 공유할 주소

발급받은 주소 뒤에 폴더 이름을 붙인다.

```
https://<발급받은주소>.netlify.app/nv39h7gq3j7pf6/
```

- 마지막 `/` 를 빠뜨리지 않는다.
- 루트(`.../`)로 들어가면 404가 뜬다 — **의도한 동작이다.** 주소를 모르면 못 들어온다.

## 3. 주소를 추측 어렵게 한 이유

이 목업에는 요금표·배상 기준·구독 손익 같은 내부 자료가 들어있다.
링크를 아는 사람은 누구나 볼 수 있으므로, 경로에 무작위 문자열을 넣어
주소를 모르면 찾을 수 없게 했다.

- Netlify가 주는 서브도메인도 무작위이고, 거기에 무작위 경로가 한 번 더 붙는다
- 검색엔진 수집 차단(noindex)은 **넣지 않았다** (요청에 따름).
  어디에도 링크되지 않은 주소라 크롤러가 스스로 찾아올 일은 사실상 없다
- 다만 **완벽한 보안은 아니다.** 링크가 유출되면 누구나 볼 수 있다.
  회의가 끝나면 Netlify에서 사이트를 지우는 것을 권한다

## 4. 목업을 고쳤을 때

`prototype/index.html` 을 수정한 뒤:

```powershell
Copy-Item prototype\index.html deploy\nv39h7gq3j7pf6\index.html -Force
```

그리고 Netlify 사이트의 **Deploys** 탭에 `deploy` 폴더를 다시 드래그하면 갱신된다.
주소는 그대로 유지된다.

## 5. 회의가 끝나면

Netlify → Site settings → **Delete this site**.
목업은 저장소에 남아 있으니 언제든 다시 올릴 수 있다.
