# 회의용 서비스 목업

**사장님 보고 → 설계 방향 확정**이 목적이다. 코드 착수 전에 이걸 먼저 보여준다.

## 여는 법

```
prototype/index.html 을 브라우저로 열면 끝 (빌드·서버 불필요)
```

배포본(회의실 화면·태블릿용): https://claude.ai/code/artifact/67e39537-794c-4d7e-ac71-7e256821e850

## 담긴 것

| 역할 | 화면 |
|---|---|
| 고객 | 홈 · 수거 신청 · 신청 확인 · 주문 추적 · **추가금 승인** · 구독 |
| 기사 | 오늘의 배차 · 수거 완료 |
| 세탁공장 | 작업 보드 · **검수 입력** |
| 관리자 | 대시보드 · 배차 보드 · **요금표 설정** · **배상 기준** |

굵은 표시 = 회의에서 반드시 짚어야 하는 화면.

요금·지역·구독 데이터는 `seed/` 초안을 그대로 썼다. 화면에서 보이는 숫자가 곧 시드 값이다.

## 회의 진행

- 좌측 목록 = 실제 서비스 흐름 순서. 위에서 아래로 따라가면 서비스 한 바퀴다.
- 우측 **"이 화면에서 정할 것"** 패널에 결정 항목 13개가 화면별로 붙어 있다. ● 는 제안하는 기본안.
- 좌측 목록의 주황 점 = 결정 항목이 있는 화면.
- `←` `→` 키로 화면 이동. 우상단에서 결정 패널을 접거나 다크 모드로 바꿀 수 있다.

## 이 목업의 한계

- **동작하지 않는다.** 버튼을 눌러도 반응 없고, 화면 이동은 좌측 목록으로만 한다.
- 데이터는 전부 고정값이다.
- 화면에 있는 금액은 요금표 초안 기준이며 실제 청구 로직을 거친 값이 아니다.
- 목적이 "이 방향이 맞는가"를 정하는 것이라, 예외 화면(오류·빈 상태·로딩)은 넣지 않았다.

## 회의 후

확정된 결정을 `seed/*.json` 과 문서 09·13에 반영한 뒤 Phase 0(모노레포 스캐폴딩)에 착수한다.
방향이 크게 바뀌면 목업을 먼저 고치고 다시 확인받는 게 코드를 고치는 것보다 싸다.
