# 지성클리닝 (JISEONG Cleaning)

세탁물 **수거 → 세탁 → 배송** O2O 서비스 플랫폼

> 최초 작성 2026-08-08 / 상태: **설계 완료, 구현 착수 전**

---

## 한 줄 요약

고객이 앱에서 수거를 신청하면 → 기사가 방문 수거 → 세탁공장에서 검수·세탁 → 기사가 배송하고,
관리자가 전 과정을 관제하는 시스템. 단일 **PWA**(웹앱)로 4개 역할을 모두 커버한다.

## 확정된 기술 선택

| 항목 | 선택 | 비고 |
|---|---|---|
| 클라이언트 | **PWA (Next.js)** | 웹 = 앱. 앱스토어 심사 불필요, 홈화면 설치 + 웹푸시 지원 |
| 백엔드 | **NestJS (Node.js/TypeScript)** | 프론트와 언어 통일, 모듈 구조가 도메인 분리에 적합 |
| DB | **PostgreSQL** | + Redis(캐시/큐), S3 호환 스토리지(사진) |
| 역할 | **고객 / 기사 / 세탁공장 / 관리자** (4역할) | |
| 결제 | **PG 결제 + 정기구독(월정액)** | 토스페이먼츠 빌링키 기반 |

## 시드 데이터 (바로 수정 가능)

`seed/` 의 JSON을 고치면 그대로 DB 시드로 들어간다. 근거와 설명은 문서 09에 있다.

| 파일 | 내용 |
|---|---|
| `seed/service-areas.json` | 경주시 23개 읍면동 + 권역(1/2/3) + 운영요일 |
| `seed/service-items.json` | 세탁 품목 46종 + 단가 |
| `seed/subscription-plans.json` | 구독 플랜 4종 |
| `seed/time-slots.json` | 수거·배송 시간대 |
| `seed/accounts.json` | 관리자·공장·기사 초기 계정 |

## 확정된 운영 조건

| 항목 | 확정 내용 |
|---|---|
| 서비스 지역 | **경주시 전역 (23개 읍면동)** — 거리 때문에 3개 권역으로 나눠 운영일 차등 |
| 세탁공장 | **자사 시설 1개소** → 공장 정산 기능 불필요 (개발 범위에서 제외) |
| 기사 | 오픈 시 **1명 직고용**, 일 처리 25건 기준 |
| 요금표 / 구독플랜 | 문서 09에 초안 완료. **숫자는 전부 수정 전제** |

## 아직 남은 확인 사항

1. **PG 계약 · 카카오 알림톡 발신프로필** (사업자등록증 필요, 7~14일 리드타임 — 가장 급함)
2. 세탁공장 실제 위치 (경주시 내 주소)
3. 기사 채용 + 차량
4. 문서 09의 요금·구독 단가 검토 및 확정
5. 읍면동 행정표준코드 (현재 임시 코드 사용 중)
6. 운영 연락처 목록 작성 (문서 12 §7)

## 개발 시작하기

아직 코드는 없다. Phase 0(모노레포 스캐폴딩)부터 시작한다 — 문서 08 참조.

```
예정 구조
├─ apps/web          # Next.js PWA (고객/기사/공장/관리자)
├─ apps/api          # NestJS
├─ packages/shared   # 상태머신·금액계산 (web/api 공용)
├─ docs/             # 설계 문서 (현재)
└─ seed/             # 마스터 데이터
```

## 브랜치 전략

| 브랜치 | 용도 |
|---|---|
| `main` | 배포 가능 상태. 직접 커밋 금지 |
| `feat/*` | 기능 개발 |
| `fix/*` | 버그 수정 |
| `docs/*` | 문서 수정 |

커밋 메시지는 [Conventional Commits](https://www.conventionalcommits.org/) 를 따른다.
`feat:` `fix:` `docs:` `chore:` `test:` `refactor:`
