# 페이지별 섹션 레시피

## 홈 (/) — 실사이트 기준(2026-08-28)
1. 히어로(navy 그라디언트): h1(RotatingWords) + 서브 1줄 + CTA 2개 + 신뢰 Badge 3개(히어로 안) + 우측 ScheduleCard + 하단 키워드 마퀴 + 물결 전환
2. 자동 슬라이드(white): 확정 2장 + 지성이엔지 자리 2장
3. 서비스(white): SectionHead + 통합 Card 1장(업종 Chip 6)
4. 절차(tint): 4단계 카드 + 연결선 grow + 순차 하이라이트
5. 적합 업종(tint): "확인 후 연락드립니다." + 칩 6 + "바로 문의하기"
6. 표준사업장(navy): 확정 문구 + 인증 배지
7. 마무리 CTA(paper): "확인 후 연락드립니다." + 버튼

## 서비스 (/services) — 실사이트 기준
PageHero → 핵심 Card(white: "하나의 서비스, 사업장마다 다른 리듬"+확정 문구+Chip 6) → 운영 방식 "이렇게 운영합니다" 3카드(tint) → 주간 리듬 ScheduleCard(navy) → 업종별 6카드(white) → 마무리 CTA(paper)

## 회사소개 (/about)
PageHero(큰/작은 글씨 확정 문구, BrandMark 워터마크) → 사업 개요 2칼럼(white: 큰 타이포+사업자 정보 Card) → 표준사업장(navy) → 거래 대상 Chip 6(white) → 파트너 맺음말 인용구(paper) + CTA

## 견적 문의 (/quote)
PageHero("확인 후 연락드립니다." 만) → 2칼럼(폼 Card + navy 연락 카드/4단계 미니 스텝) → ReviewMarquee(tint) + SnsButtons → 찾아오는 길(white)
폼 필드는 업체명*·성함·연락처*·주소·이메일·문의 내용·개인정보 동의* 만. 업종/품목/물량/주기 필드 금지.
