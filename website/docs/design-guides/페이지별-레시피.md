# 페이지별 섹션 레시피

## 홈 (/)
1. 히어로(navy 그라디언트): h1(RotatingWords: 사업장 세탁물을→호텔 시트를→펜션 이불을→사우나 수건을) + 서브 1줄 + CTA 2개(onNavy/onNavyGhost) + 우측 ScheduleCard + 하단 키워드 마퀴(정기 수거·전문 세탁·살균 공정·건조 정리·약속한 날짜 배송·월 단위 정기 계약·사업장 전용)
2. 신뢰 스트립(white): Badge 3(장애인 표준사업장/월 단위 정기 계약 가능/자체 세탁 시설)
3. 서비스(tint): SectionHead + 통합 Card 1장(업종 Chip 6)
4. 절차(white): 4단계 카드 + 연결선
5. 표준사업장(navy): 확정 문구 + 인증 배지
6. 마무리 CTA(paper): "확인 후 연락드립니다." + 버튼

## 서비스 (/services)
PageHero → 핵심 Card(확정 문구+Chip 6) → 운영 방식 3카드(tint) → ScheduleCard 크게(navy) → 마무리 CTA(paper)

## 회사소개 (/about)
PageHero(큰/작은 글씨 확정 문구, BrandMark 워터마크) → 사업 개요 2칼럼(white: 큰 타이포+사업자 정보 Card) → 표준사업장(navy) → 거래 대상 Chip 6(white) → 파트너 맺음말 인용구(paper) + CTA

## 견적 문의 (/quote)
PageHero("확인 후 연락드립니다." 만) → 2칼럼(폼 Card + navy 연락 카드/4단계 미니 스텝) → ReviewMarquee(tint) + SnsButtons → 찾아오는 길(white)
폼 필드는 업체명*·성함·연락처*·주소·이메일·문의 내용·개인정보 동의* 만. 업종/품목/물량/주기 필드 금지.
