# 지성크리닝 — 페이지 구성 규칙 (디자인 에이전트용)

콘텐츠가 적은 사업장 세탁 서비스다. 텍스트를 늘리지 말고 아래 규칙으로 "깔끔하고 풍부한" 밀도를 만든다.

## 품질 기준 (이 수준 미달이면 다시)
- 섹션 배경은 paper/white/tint/navy 로 리듬을 만든다. 같은 톤이 연속될 땐 구분 요소(보더·카드·여백 변화)를 넣는다 (실사이트 기준).
- 네이비 섹션은 페이지당 1~2개만. 나머지는 밝게 (청결감).
- 히어로는 화면 70% 이상 높이 + 좌 텍스트/우 시각물(ScheduleCard 등) 2칼럼. 텍스트만 덩그러니 놓지 않는다.
- 모든 섹션에 SectionHead(eyebrow+title+lede)로 위계를 만들고, 카드에는 IconBubble·Chip·Badge로 시각 밀도를 채운다.
- 모션 필수: Reveal 스크롤 등장(시차 70ms 간격), hover 리프트, 마퀴·RotatingWords·AutoSlider 중 페이지당 최소 1개.
- 한 섹션 = 메시지 하나. 여백을 두려워하지 말 것.

## 절대 금지
- 취급 품목 나열·가격/단가 표·FAQ 섹션·연혁 타임라인 (전부 삭제 결정된 요소)
- 부정형 문장("~하지 않습니다"), "24시간", 납품·배달·린넨·고온·업소용·천북 단어
- 임의 색 발명 (네이비 위에는 tone="dark"/onNavy 변형 사용)
- 가짜 채움 텍스트 (문구가 없으면 [문구 확정 필요] 로 표시)

- 서비스: "사업장 규모, 품목과 물량에 따라 주기적으로 관리해 드립니다" / "안전한 세탁·살균을 거쳐 약속된 날짜에 수거, 배송해 드립니다."
