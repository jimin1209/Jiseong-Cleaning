# 지성크리닝 결정사항 (Codex 확정 지침서)

> ⚑ **우리는 도매(B2B)입니다.** 지성크리닝은 **개인 손님이 아니라 업체(거래처)** 세탁물만 대량으로 수거·세탁·납품합니다.
> (예: 호텔·모텔 침구/수건, 식당 앞치마/행주, 헬스장 수건/가운) → 이 문서의 "고객"은 전부 **거래처(업체)**, "배송"은 **납품**입니다.
>
> 이 문서는 **Codex에게 "이건 이미 정해졌으니 임의로 만들지 마"라고 알려주는 확정 지침서**입니다.
> 미결정 상태로 개발을 시작하면 Codex가 마음대로 만들어 나중에 갈아엎게 됩니다. 그래서 먼저 정합니다.
>
> - 값 표기 규칙
>   - ✅ **확정** : 이미 정해짐. Codex는 이대로 따른다.
>   - 🧪 **데모용(임시)** : 4일 데모에선 이 값으로 하고, 정식 개발 때 진짜로 교체.
>   - ⛔ **[대표 확정 필요]** : 대표·팀장이 정해야 함. 정하기 전엔 옆의 "데모 기본값"으로 진행.
> - 짝 문서: `명세서.md`(무엇), `개발 설계서.md`(어떻게), `4일-집중-개발일정.md`(언제)
> - 출처: 명세서 8장 / 설계서 19장 / 4일 일정 9장의 "확정 필요 사항"을 **도매(B2B) 기준으로 재정리**
> - ⚠️ 원본 명세서·설계서는 개인 고객(B2C) 표현이 남아있습니다. **충돌 시 이 문서(도매 기준)를 우선**합니다.

## 1. 인증 · 계정

### 1-1. 거래처 로그인 방식
- **정식:** ⛔ [대표 확정 필요] — 개인 본인인증이 **아니라** 거래처 계정 방식. (관리자가 거래처 계정 발급 / 아이디·비밀번호 / 담당자 휴대폰 인증 중 택)
- **데모 기본값:** 🧪 **거래처명(업체명)만 입력하면 로그인**(예: 행복호텔, 진짜 인증 없음)
- Codex 지시 요지: "지금은 실제 인증 대신, 거래처명만 넣으면 로그인되는 테스트용으로 만들어라. 개인 회원가입 화면은 만들지 마라."

### 1-2. 신규 거래처 등록 방식
- ⛔ [대표 확정 필요] — 개인 셀프 회원가입 없음. 관리자가 **거래처를 등록·승인**하는 방식.
- **데모 기본값:** 🧪 관리자가 미리 넣어둔 샘플 거래처로 로그인. 셀프 가입 흐름 없음.

### 1-3. 관리자 계정 / 권한 등급
- **정식:** 최고 관리자 / 일반 관리자 / 기사(수거·납품) / 세탁공장 **4역할**, 역할별 권한(설계서 4장)
- **데모 기본값:** 🧪 '관리자로 시작' 버튼 하나로 단일 관리자. 권한 분리는 정식 단계에서.

## 2. 주문 · 금액 · 정산

### 2-1. 결제(정산) 시점
- ⛔ [대표 확정 필요] — 도매는 보통 **건별 선결제가 아니라 월 마감 후불 정산**이 흔함. (건별 / 월 정산 / 혼합 중 택)
- **명세서 기준 흐름:** 신청 시 **예상 금액** → 수거·검수 후 **최종 금액 확정**(실제 수량·상태 반영) → 정산
- **데모 기본값:** 🧪 **가짜 정산**(결제/정산 단계는 버튼만). 상태 흐름만 시연.

### 2-2. 정산 수단 / 세금계산서
- ⛔ [대표 확정 필요] — 거래처 대상이므로 **세금계산서 발행·계좌이체·월 청구서**가 카드결제보다 우선일 수 있음.
- **데모 기본값:** 🧪 진짜 결제/세금계산서 연동 없음. "정산 완료" 표시로 대체.

### 2-3. 최종 금액 승인 정책
- ⛔ [대표 확정 필요] — 승인이 필요한 조건(수량/금액 차이 기준), 무응답 시 처리, 응답 제한 시간
- **데모 기본값:** 🧪 승인 단계 단순화(관리자가 최종금액 확정하면 다음 상태로 진행).

### 2-4. 금액 계산 위치 (원칙 · 고정)
- ✅ **확정: 금액 계산은 반드시 서버에서 한다. 화면에서 보낸 금액을 믿지 않는다.**
- 데모에서도 예상금액 합산은 서버가 계산. (수량 × 거래처 단가)

### 2-5. 거래처 단가 · 최소 물량 · 수거/납품비
- ⛔ [대표 확정 필요] — 도매는 **거래처별 단가(계약가)**가 다를 수 있음. 최소 접수 물량, 수거·납품비 정책.
- **데모 기본값:** 🧪 모든 거래처 동일 단가, 최소 물량 없음, 수거·납품비 0원(예상금액 = 품목단가 × 수량 합).

### 2-6. 샘플 품목 · 단가 (데모 시드 데이터 — 업소용 대량 기준)
- 🧪 **데모용 확정(1장당 단가, 출처: `품목-단가표.md` 표준, 데모 화면과 동일):** 호텔 시트 800원 · 베개 커버 500원 · 대형 수건 600원 · 가운 1,500원 · 식당 앞치마 900원
- 주문은 **대량 수량**으로(예: 시트 120, 수건 200). 정식에선 관리자 품목·단가 관리 화면에서 등록(명세서 4.9).
