## 1. 인증 · 계정

### 1-1. 거래처 로그인 방식 　【우선】
- **질문:** 거래처(업체)가 어떻게 로그인하나요? (개인 본인인증 아님)
- **선택:** [v] 관리자가 계정 발급 　[v] 아이디·비밀번호 　[ ] 담당자 휴대폰 인증 　[ ] 혼합
- **데모 기본값(참고):** 거래처명만 입력하면 로그인(가짜)
- **결정(초안):** 관리자가 거래처 계정을 발급하고, 담당자는 아이디·비밀번호로 로그인. 휴대폰 인증은 정식 단계에서 검토.
- 담당:______ 기한:______

### 1-2. 신규 거래처 등록 방식
- **질문:** 새 거래처를 어떻게 받나요? (개인 셀프가입 없음)
- **선택:** [ ] 관리자가 등록·승인 　[v] 거래처가 신청 → 관리자 승인
- **데모 기본값:** 관리자가 샘플 거래처 미리 등록
- **결정(초안):** 거래처가 사업자등록번호·상호·담당자 정보로 신청하면, 관리자가 확인 후 승인·계정 발급.
- 담당:______ 기한:______

### 1-3. 관리자 계정·권한 등급
- **질문:** 관리자 권한을 나눌까요? (최고관리자/일반/기사/세탁공장)
- **선택:** [ ] 단일 관리자 　[v] 역할별 권한 분리
- **데모 기본값:** 단일 관리자
- **결정(초안):** 최고관리자·일반관리자·기사·세탁공장으로 분리(정식). 데모는 단일 관리자로 진행.
- 담당:______ 기한:______

## 2. 발주 · 금액 · 정산

- **선택:** [ ] 건별 선결제 　[v] 월 마감 후불 정산 　[ ] 혼합
- **데모 기본값:** 가짜 정산(버튼만, 상태 흐름만 시연)
- **결정(초안):** 월 마감 후불 정산. 매월 말일 마감 → 익월 10일 세금계산서 발행 → 익월 말일까지 입금.

### 2-2. 정산 수단·세금계산서 　【우선】

- **선택:** [v] 세금계산서 발행 　[v] 계좌이체 　[ ] 월 청구서 　[ ] 카드(건별)
- **세금계산서 발행 방법:** [ ] 홈택스 　[v] 팝빌 등 대행 　[ ] 미정
- **데모 기본값:** 진짜 연동 없음, "정산 완료" 표시로 대체
- **결정(초안):** 월 마감분을 세금계산서로 발행(팝빌 등 전자세금계산서 대행), 계좌이체로 수납.

### 2-3. 최종 금액 승인 정책
- **질문:** 검수 후 금액이 달라지면 거래처 승인을 받나요? 어떤 차이부터?
- **결정(초안):** 예상 대비 **금액 10% 또는 20,000원 이상** 차이 나면 거래처 승인 필요. 무응답 시 **영업일 1일 후 관리자 확인 후 진행**. 응답 제한: **24시간**.
- **데모 기본값:** 승인 단계 단순화(관리자 확정 시 바로 진행)
- 담당:______ 기한:______

### 2-4. 금액 계산 위치 (원칙 · 확정 · 논의 불요)
- **확정:** 예상·최종 금액은 **반드시 서버에서** 계약 단가로 계산한다. 화면이 보낸 금액은 신뢰하지 않는다.
- (이미 확정된 개발 원칙이라 회의에서 정할 필요 없음. 번호 추적용 표기.)

### 2-5. 거래처 단가·최소 물량·수거/납품비 　【우선】
- **질문:** 단가를 거래처마다 다르게 하나요? 최소 물량·수거납품비는?

- **데모 기본값:** 동일 단가, 최소물량 없음, 수거·납품비 0원
- 담당:______ 기한:______
