## 1. 인증 · 계정

### 1-1. 거래처 로그인 방식 　【우선】
- **질문:** 거래처(업체)가 어떻게 로그인하나요? (개인 본인인증 아님)
- **선택:** [ ] 관리자가 계정 발급 　[ ] 아이디·비밀번호 　[ ] 담당자 휴대폰 인증 　[ ] 혼합
- **데모 기본값(참고):** 거래처명만 입력하면 로그인(가짜)
- **결정:** ________________________________________________
- 담당:__________ 기한:__________

### 1-2. 신규 거래처 등록 방식
- **질문:** 새 거래처를 어떻게 받나요? (개인 셀프가입 없음)
- **선택:** [ ] 관리자가 등록·승인 　[ ] 거래처가 신청 → 관리자 승인
- **데모 기본값:** 관리자가 샘플 거래처 미리 등록
- **결정:** ________________________________________________
- 담당:__________ 기한:__________

### 1-3. 관리자 계정·권한 등급
- **질문:** 관리자 권한을 나눌까요? (최고관리자/일반/기사/세탁공장)
- **선택:** [ ] 단일 관리자 　[ ] 역할별 권한 분리
- **데모 기본값:** 단일 관리자
- **결정:** ________________________________________________
- 담당:__________ 기한:__________
